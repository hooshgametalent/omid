# نیازمندی‌های اولیهٔ پلتفرم جرثقیل صنعتی

- **شناسه:** `industrial-crane-platform`
- **وضعیت:** `Draft / نیازمند تأیید کارفرما`
- **نسخه سند:** `0.1`
- **آخرین به‌روزرسانی:** `2026-10-30`
- **مرجع backlog:** [tasks.md](./tasks.md)

## 1. واقعیت‌های قطعی

1. کسب‌وکار، طراح و سازندهٔ جرثقیل‌های صنعتی است.
2. وب‌سایت باید بخش فروشگاهی برای عرضهٔ لوازم و قطعات داشته باشد.
3. هر نوع جرثقیلی که شرکت قابلیت تولید آن را دارد، باید صفحهٔ اختصاصی محتوایی شبیه مقاله/صفحهٔ توانمندی داشته باشد؛ این صفحه نباید محصول فروشگاهی تلقی شود.
4. محصولات فروشگاه و صفحات اختصاصی جرثقیل‌ها باید الزامات SEO را پوشش دهند.
5. تمام تصاویر ورودی از مسیر upload/import باید به WebP تبدیل و در چند اندازهٔ استاندارد تولید شوند.
6. اولین خروجی قابل ارائه، نمونهٔ بصری تمام نوع‌صفحه‌ها با محتوای آزمایشی است.
7. فناوری پایهٔ نصب‌شده:
   - PHP `8.2.0`
   - Laravel Framework `12.70.2`
   - Livewire `4.4.8`
   - Tailwind CSS `4.x`
   - Vite `7.3.7`
8. اجرا، نصب، build و test فقط روی محیط محلی انجام می‌شوند؛ انتشار یا عملیات Git در scope فعلی نیست.

## 2. فرض‌های موقت

این موارد تا زمان تأیید کارفرما fact محسوب نمی‌شوند:

- زبان اصلی نسخهٔ اول فارسی و جهت رابط RTL است.
- پروژه برای یک شرکت و به‌صورت single-site طراحی می‌شود؛ multi-tenancy فعلاً نیاز نیست.
- هدف اصلی صفحات شرکتی و جرثقیل‌ها ایجاد اعتماد و دریافت درخواست مشاوره/استعلام است.
- منظور از «تمام صفحات» در milestone بصری، تمام **نوع‌صفحه‌ها، layoutها و stateهای ضروری** است، نه ایجاد محتوای واقعی برای تک‌تک رکوردها.
- نمونهٔ بصری با دادهٔ ساختگی و بدون پرداخت، ارسال سفارش یا پردازش واقعی import ارائه می‌شود.
- پنل مدیریت اختصاصی با Laravel/Livewire ساخته می‌شود و استفاده از admin generator پیش‌فرض نیست.
- اندازه‌های کاندیدای تصاویر responsive عبارت‌اند از `320، 480، 768، 1024، 1280، 1600 و 1920px`؛ preset نهایی بعد از تثبیت layout و نوع تصویر تأیید می‌شود.
- تصاویر کوچک‌تر از preset بدون نیاز upscale نمی‌شوند و نسبت تصویر حفظ می‌شود، مگر crop مشخصی برای component تعریف شود.

- ارائهٔ تجربهٔ سریع، responsive، دسترس‌پذیر و قابل استفاده در موبایل، تبلت و دسکتاپ.

## 5. مرزبندی دامنه

### 5.1 موجودیت محتوایی جرثقیل

`CraneCapability` یک صفحهٔ محتوایی مستقل است و با `Product` فروشگاه یکی نیست. این صفحه می‌تواند شامل معرفی، کاربردها، ظرفیت/دهانه/ارتفاع، گزینه‌های طراحی، فرایند ساخت، استانداردها، گالری، FAQ، پروژه‌های مرتبط، محصولات مرتبط و CTA استعلام باشد. نوع structured data آن فقط پس از بررسی محتوای واقعی انتخاب می‌شود و به‌صورت پیش‌فرض `Product` نیست.

### 5.2 محصول فروشگاه

`Product` برای لوازم، قطعات و اقلام قابل فروش/استعلام است و می‌تواند قیمت، SKU، موجودی، ویژگی، گالری، شرایط خرید و structured data متناسب داشته باشد. وجود checkout و پرداخت آنلاین هنوز تصمیم‌گیری نشده است.

### 5.3 milestone بصری

نمونهٔ بصری باید navigation واقعی‌نما، routeهای نمایشی، componentهای reusable، محتوای آزمایشی مشخص‌شده و stateهای اصلی داشته باشد. اتصال کامل به database، درگاه پرداخت، موتور سفارش و import واقعی جزو معیار پذیرش این milestone نیست.

## 10. معیار خروج milestone بصری

Milestone بصری زمانی آمادهٔ ارائه است که:

1. تمام page typeهای مصوب و stateهای ضروری قابل پیمایش باشند.
2. سه محدودهٔ viewport مصوب بررسی شده باشند.
3. محتوای آزمایشی، تصویرهای placeholder و claimهای تأییدنشده مشخص باشند.
4. صفحات جرثقیل و محصول از نظر هدف، template و URL از هم جدا باشند.
5. metadata و نمونهٔ structured-data intent در spec هر page type مشخص باشد، بدون ادعای validation production.
6. پنل اختصاصی حداقل flowهای اصلی را به‌صورت visual mock نشان دهد.
7. QA بصری، keyboard review و بررسی overflow انجام شده باشد.
8. کارفرما بازخورد هر page type را ثبت و design direction را تأیید کرده باشد.
